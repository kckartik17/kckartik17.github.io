200. Number of Islands

source: neetcode.io
🔗 leetcode.com/problems/number-of-islands
Count connected components of '1' cells using 4-directional adjacency only.
Ex: 4×5 grid with four separate land blobs → 4  |  m,n ≤ 100, cells are '0' or '1'   |   Goal → O(m·n) time & space
Prereqs: 2D grid traversal • DFS/BFS connected-component flood fill • Union-Find for merging adjacent land

1. Depth First Search optimal

Intuition: Each unseen '1' starts a new island. DFS "sinks" that whole component by flipping land to water, so you never count the same island twice.
  1. Scan every cell (r, c).
  2. On '1': run DFS, then increment island count.
  3. DFS: out of bounds or '0' → return; else set '0' and recurse 4 ways.
  4. Return total count after full scan.
O(m·n) time · O(m·n) space
Use when: default interview answer—short, intuitive flood fill on a grid.

2. Breadth First Search linear

Intuition: Same connected-component idea, but expand layer-by-layer with a queue instead of recursion. Still mark each visited land cell as '0'.
  1. Scan grid; on '1', start BFS and bump count.
  2. Enqueue start cell; mark it '0' immediately.
  3. Dequeue, push any unvisited land neighbors (mark '0' on enqueue).
  4. Repeat until queue empty; continue scan.
O(m·n) time · O(m·n) space
Use when: avoiding recursion depth or you prefer iterative level-order expansion.

3. Disjoint Set Union union-find

Intuition: Count every land cell, then union with adjacent land neighbors. Each successful merge means two cells were one island—decrement the running total.
  1. Map (r,c) → index r·cols+c; init DSU for m·n cells.
  2. For each '1': islands++; check 4 neighbors.
  3. If neighbor is land and union succeeds, islands−−.
  4. Return final islands count.
O(m·n) time · O(m·n) space
Use when: dynamic connectivity pattern or interviewer asks for Union-Find.

Interview Code C++ · DFS

class Solution {
    int dirs[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};
public:
    int numIslands(vector<vector<char>>& grid) {
        int rows = grid.size(), cols = grid[0].size(), islands = 0;
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++)
                if (grid[r][c] == '1') { dfs(grid, r, c); islands++; }
        return islands;
    }
    void dfs(vector<vector<char>>& g, int r, int c) {
        if (r<0||c<0||r>=g.size()||c>=g[0].size()||g[r][c]=='0') return;
        g[r][c] = '0';
        for (auto& d : dirs) dfs(g, r+d[0], c+d[1]);
    }
};
Say in interview: O(m·n) visits each cell once. In-place '0' marking avoids extra visited set. 4-directional only—no diagonals. Check bounds before access.

⚠ Common Pitfalls

• Forgetting to mark visited → infinite DFS/BFS loops.
• Incrementing count for every '1' instead of per new component.
• Using 8-directional (diagonal) neighbors—merges separate islands.

💡 Interview Tip

Frame it as "count connected components." Code DFS first; mention BFS swap and Union-Find if asked. Sink cells in-place or use a visited set—state that choice aloud.
