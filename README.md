# DSA Handwritten Notes

One-page LeetCode revision sheets (handwritten notebook style), hosted on GitHub Pages.

## Live site

After publishing, your notes will be at:

**https://kckartik17.github.io/**

## Local preview

Open `index.html` in a browser, or run:

```powershell
cd "C:\Users\KartikChauhan\OneDrive - SirionLabs Pvt. Ltd\Documents\DSA Notes"
python -m http.server 8080
```

Then visit http://localhost:8080

## Publish / update

```powershell
cd "C:\Users\KartikChauhan\OneDrive - SirionLabs Pvt. Ltd\Documents\DSA Notes"
git add .
git commit -m "Add or update notes"
git push
```

GitHub Pages redeploys automatically within ~1–2 minutes.

## Adding a new note

1. Save the new HTML file in this folder (e.g. `two-sum-notes.html`).
2. Add a link in `index.html`.
3. Commit and push.
