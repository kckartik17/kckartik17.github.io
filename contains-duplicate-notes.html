217. Contains Duplicate

source: neetcode.io
🔗 neetcode.io/solutions/contains-duplicate
Decide whether any integer in the array shows up more than once.
Ex: [1,2,3,3] → true  |  [1,2,3,4] → false   |   n ≤ 105, nums[i] ∈ [−109, 109]   |   Goal → O(n) time, O(n) space
Prereqs: Hash sets (O(1) membership checks), sorting (grouping equal values), basic array traversal with nested loops

1. Brute Force easiest

Intuition: Walk every unordered pair of indices and compare their values. The moment two different positions hold the same number, a duplicate exists.
  1. Outer loop picks index i; inner loop picks j from i + 1 onward.
  2. If nums[i] equals nums[j], return true immediately.
  3. Finish both loops with no match → return false.
O(n²) time · O(1) space
Use when: tiny inputs or you need zero extra memory and can accept quadratic time.

2. Sorting in-place

Intuition: Sorting places equal values side by side. One left-to-right pass comparing each element to its left neighbor reveals any repeat.
  1. Sort nums in non-decreasing order.
  2. Loop from index 1 to end.
  3. If nums[i] == nums[i − 1], return true.
  4. No adjacent match after full scan → return false.
O(n log n) time · O(1) or O(n) space
Use when: you may mutate the input and want better-than-quadratic time without a hash table.

3. Hash Set optimal

Intuition: Track numbers already visited in a set. Before inserting the current value, ask whether it is already there — that is an instant duplicate hit.
  1. Create an empty hash set called seen.
  2. For each num in nums: if num is in seen, return true.
  3. Otherwise insert num into seen.
  4. Loop ends with no collision → return false.
O(n) time · O(n) space
Use when: interview default — single pass, early exit, preserves input order.

4. Hash Set Length one-liner

Intuition: A set keeps only unique entries. If building a set from the array shrinks the count, at least one value must have appeared twice.
  1. Build a set from all elements of nums.
  2. Compare set.size (or len) with nums.length (or len).
  3. If set is smaller, return true (duplicates were dropped).
  4. Equal sizes → return false.
O(n) time · O(n) space
Use when: you want the shortest code; same logic as approach 3 but no early stop.

Dry Run — Hash Set on [1, 2, 3, 3]

Start
seen = {}
num = 1

num = 3

num = 3
3 already in seen → return true

Interview Code C++ · Hash Set

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        for (int num : nums) {
            if (seen.count(num)) return true;
            seen.insert(num);
        }
        return false;
    }
};
Say in interview: one pass, unordered_set for O(1) lookup, return early on repeat. Alt: if (!seen.insert(num).second) return true;

⚠ Common Pitfalls

• Brute force: inner loop must start at i + 1, not i, or you compare an element to itself.
• Sorting mutates the original array — copy first if order must be preserved.

💡 Interview Tip

Start with brute force to show you understand the question, mention sorting as a trade-off, then land on the hash set for O(n). Mention the set-length trick only as a concise variant.
