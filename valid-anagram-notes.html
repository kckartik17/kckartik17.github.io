242. Valid Anagram

source: neetcode.io
🔗 leetcode.com/problems/valid-anagram
Decide whether two strings use the exact same multiset of lowercase letters.
Ex: s="racecar", t="carrace" → true  |  s="jar", t="jam" → false   |   n,m ≤ 5×104, lowercase a–z   |   Goal → O(n+m) time, O(1) space
Prereqs: Hash maps for per-char counts • Sorting for canonical reordering • Fixed-size arrays when alphabet is bounded (26 letters)

1. Sorting easiest

Intuition: Anagrams share the same letter counts; sorting puts both strings in identical order. If the sorted results match, every character frequency must match too.
  1. Return false immediately if lengths differ.
  2. Sort both strings character-wise.
  3. Compare sorted strings; equal → true, else false.
O(n log n + m log m) time · O(1)* space
Use when: you want the shortest code and sorting cost is acceptable.

2. Hash Map linear

Intuition: Skip sorting—walk both strings once and tally how often each letter appears. Matching frequency maps means the strings are anagrams.
  1. Return false if lengths differ.
  2. Build two hash maps counting chars in s and t.
  3. Increment counts while scanning both strings in parallel.
  4. Return whether the two maps are equal.
O(n + m) time · O(1) space
Use when: alphabet size is unknown or you want a general frequency-count pattern.

3. Hash Table (Array) optimal

Intuition: Only 26 lowercase letters exist, so a length-26 array replaces hash maps. Bump counts for s, drop counts for t; all zeros at the end means perfect cancellation.
  1. Return false if lengths differ.
  2. Create count[26], all zeros.
  3. For each index i: count[s[i]-'a']++, count[t[i]-'a']--.
  4. If every slot is 0, return true; else false.
O(n + m) time · O(1) space
Use when: fixed lowercase alphabet—fastest interview answer with no hash overhead.

Interview Code C++ · Array Counter

class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.length() != t.length()) return false;

        vector<int> count(26, 0);
        for (int i = 0; i < s.length(); i++) {
            count[s[i] - 'a']++;
            count[t[i] - 'a']--;
        }
        for (int val : count)
            if (val != 0) return false;
        return true;
    }
};
Say in interview: O(n+m) single pass with O(1) space (26 slots). Length check first. Increment/decrement trick avoids building two maps—mention you can early-exit if any count goes negative.

⚠ Common Pitfalls

• Skipping the length check wastes work on impossible cases.
• Mixed-case inputs need normalization; here all lowercase is guaranteed.
• Using one map for both strings without +/- can double memory unnecessarily.

💡 Interview Tip

Start with sorting (quick to code), then improve to hash maps, then tighten to the 26-slot array when you note the alphabet bound. State target O(n+m) / O(1) before coding the optimal version.
